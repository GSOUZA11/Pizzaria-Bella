# 🍕 Pizza Bella

Landing Page da **Pizza Bella** — uma pizzaria com mais de 10 anos de tradição, desenvolvido com HTML, CSS e Bootstrap 5.

---

## 🌐 Deploy

Acesse o site online:

🔗 **(https://pizzaria-bella01.netlify.app/)**

---

## 📋 Sobre o Projeto

A Pizza Bella é apaixonada pela arte de fazer pizza de verdade. Este site foi criado para apresentar o cardápio, promoções, informações sobre a pizzaria e um canal de contato direto com os clientes.

---

## 📸 Seções do Site

| Seção | Descrição |
|---|---|
| 🏠 **Home** | Carrossel com imagens e frases de destaque |
| ⭐ **Destaques** | Forno a lenha, ingredientes frescos, entrega rápida e tradição |
| 🔥 **Promoções & Combos** | Cards com combos especiais e preços |
| 🍕 **Cardápio** | Cards com os sabores disponíveis |
| ℹ️ **Sobre Nós** | História e diferenciais da pizzaria |
| 📞 **Contato** | Formulário de contato e informações da loja |

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3** — estilos personalizados com animações e transições
- **[Bootstrap 5.3.8](https://getbootstrap.com/)** — layout responsivo e componentes
- **[Bootstrap Icons 1.13.1](https://icons.getbootstrap.com/)** — ícones
- **Google Fonts** — fonte Poppins

## ✨ Funcionalidades de Estilo

- **Scroll suave** entre as seções com `scroll-behavior: smooth`
- **Carrossel responsivo** com legendas adaptadas para cada tamanho de tela
- **Efeito parallax** no fundo da seção de contato
- **Hover animado** nos ícones de contato e redes sociais
- **Transições suaves** em botões, inputs e ícones (`0.3s ease`)

## 💻 Como Rodar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/GSOUZA11/Pizzaria-Bella.git
```

2. Acesse a pasta do projeto:
```bash
cd Pizzaria-Bella
```

3. Abra o arquivo `index.html` no navegador — sem necessidade de instalar nada.
